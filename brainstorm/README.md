# Brainstorm

Scratch space for thinking out loud before anything gets committed to code or architecture. Notes, research, open questions, half-formed ideas, sketches of data models — all welcome here.

Nothing in this folder is authoritative. When an idea solidifies, it graduates out (to `data-model/`, `docs/`, ADRs, code, etc.) and the brainstorm note either gets deleted or kept as historical context.

## What's here

- `RESEARCH.md` — Belgian market research (competitors, payments, regulations, positioning)

## How to use

- One file per topic. Name them so you can tell at a glance what's inside (`orders-flow.md`, `payments-questions.md`, `tenancy-tradeoffs.md`).
- Date-stamp decisions or conclusions when they matter — brainstorm notes age fast.
- Contradictions are fine; this is where we work things out.
